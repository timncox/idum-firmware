The House, Techno, Breaks, Hip-hop and User slots play the patterns built into the firmware. You can swap in your edits from the web programmer or the ones in a .hex.

What this is and isn't

It runs the firmware's own code: every engine, knob reading, pattern, LED and output timing, plus the stock IDUM modes with CYCLE down. It does not run the AVR chip itself, so the timer setup for VCO mode, the real interrupt timing, the analog front end and the output stage are modelled, not emulated. The audio is a model of the outputs: drum sounds stand in for whatever the triggers would hit, and raw mode is the ideal square at the jack.
